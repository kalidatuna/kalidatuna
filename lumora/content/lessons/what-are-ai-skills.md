Every time you explain the same thing to an AI ("I run a bakery, keep it friendly, use British spelling, format it like this…"), you're wasting time. The fix is to **package your know-how once** so the AI uses it automatically. The industry has many names for this. Here's what they all mean.

## The five ways to "teach" an assistant

Think of them as a ladder, from simplest to most powerful:

| Feature | What it is | Best for |
| --- | --- | --- |
| **Custom instructions** | A standing note about you and your preferences, applied to every chat | Tone, units, language, who you are |
| **Memory** | The assistant remembers useful facts from your chats over time | Ongoing personal context |
| **Projects** | A workspace with its own files, instructions and chat history | An ongoing piece of work: a renovation, a course, a client |
| **Custom assistants** (custom GPTs in ChatGPT, Gems in Gemini) | A named mini-assistant with its own instructions and reference files | A repeatable job you or others do often |
| **Skills** (e.g. Claude Skills) | A packaged "how-to" folder: instructions, templates, sometimes scripts, which the assistant loads automatically when the task calls for it | Doing a specific task *your* way, every time, across chats |

## An analogy: training a new team member

- **Custom instructions** = telling them about the company on day one.
- **Memory** = them remembering things you've mentioned along the way.
- **Projects** = giving them a folder for each client.
- **Custom assistants** = hiring a specialist for one job ("the proposal writer").
- **Skills** = handing them the company playbook for a specific task, which they pull out whenever that task comes up.

## What makes skills special

A skill is essentially **a written procedure plus supporting materials**. For example, a "Monthly newsletter" skill might contain:

- Step-by-step instructions for writing your newsletter.
- Your brand voice guidelines.
- A template and two past examples.
- A checklist to run before sending.

Once installed, you just say "write this month's newsletter about the spring menu", and the assistant follows your procedure without you re-explaining anything. Different apps implement this differently, but the idea is the same everywhere: **write it down once, reuse it forever.**

> [!TIP]
> You don't need to be technical. A skill is mostly clear writing. If you can write instructions for a human colleague, you can write a skill.

## Which should you use?

- Start with **custom instructions** today (5 minutes).
- Use a **project** for anything you'll return to over weeks.
- Build a **custom assistant or skill** when you notice yourself doing the same type of task 3+ times.

## Key takeaways

- Custom instructions, memory, projects, custom assistants and skills are all ways to stop repeating yourself.
- Skills package a procedure plus materials so the AI does a task your way automatically.
- Build one when you've done the same task three times.
